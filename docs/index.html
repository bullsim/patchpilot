PatchPilot

Keep every machine up to date — automatically.

One slick app that updates your whole fleet — Windows, macOS, Linux and Raspberry Pi. It runs winget, Microsoft Store, Chocolatey, Scoop, WSL, brew, apt, flatpak, snap, firmware, even Home Assistant — only updating what's already installed. Daily scheduler, system tray, desktop notifications, and it updates itself.

Install once per machine — after that PatchPilot updates itself. Unsigned build: on first launch choose “More info → Run anyway” (Windows) or right-click → Open (macOS).

What it does

Update-only. Upgrades what's installed; never force-installs new software.
Per-machine detection. Shows only the components that machine actually has.
Daily scheduler. Runs headless via Task Scheduler / launchd / systemd, then auto-reboots if firmware needs it.
Home Assistant. Updates Core / OS / add-ons via the HA API (no add-on needed).
System tray + notifications. Run from the tray; get a toast when it's done.
Signed self-update. Each release is cryptographically signed; machines pull it automatically.
